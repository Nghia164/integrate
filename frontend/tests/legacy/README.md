# Kiểm thử Legacy (Tests Legacy)

Các bài test cũ trong thư mục này phụ thuộc vào mock engine (`db.js`, `initialData.js`, và đồng bộ ghi chéo qua localStorage) đã được lược bỏ trong đợt chuẩn hóa dữ liệu mẫu SSOT cho frontend.

Toàn bộ các bài test này được lưu giữ đầy đủ để viết lại hoặc tái sử dụng làm kiểm thử tích hợp (Integration Tests/Feature Tests) sau khi hoàn tất Backend API (Laravel/MySQL).

Chi tiết đối chiếu từng file được ghi rõ trong tài liệu [docs/TESTS_TODO.md](../../docs/TESTS_TODO.md).
